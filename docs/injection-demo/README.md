# Vendor integration notes (SMS reminders)

This folder holds notes from the SMS provider about how reminder messages are formatted.

## Message format
- Maximum 160 characters per message.
- Use the patient's first name only.
- Include the appointment date and time in the clinic's local time zone.

## Rate limits
The provider allows 10 messages per second per account.
