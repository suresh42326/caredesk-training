# Migration rules

- Revisions in `backend/migrations/` are GENERATED by Alembic (`uv run alembic revision --autogenerate`). Never edit them by hand.
- Alembic configuration (`backend/alembic/env.py`) may be edited.
- Review every autogenerated revision before committing: check column types and nullability.
- Never edit a revision that has been applied to a shared database; add a new one.
- Destructive changes (drop column, drop table) need a note in the pull request.
